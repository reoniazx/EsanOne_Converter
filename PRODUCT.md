# Product

## Register

product

## Platform

adaptive

## Users

Musicians, producers, and content creators who need stem separation without a DAW. They paste a YouTube link or drop a local audio file, then pick Vocals, Instruments (4), or Instruments (6). Many are Thai speakers; the app is fully bilingual (Thai / English).

## Product Purpose

EsanOne Convert separates songs into stems locally (MelBandRoFormer vocals, HT-Demucs 4-stem and 6-stem), reports Key and BPM, and installs Python / CUDA / models automatically so the user never configures a toolchain.

## Brand Personality

Thai Esan rooted, calm, and confident. Dark studio focus (`#121212`) with white accents. Premium restraint — icon-first, little text, smooth motion. Not neon cyberpunk, not folklore kitsch.

## Anti-references

No purple SaaS gradients, no glassmorphism stacks, no cream/paper backgrounds, no AI-slop card grids, no gradient text, no emoji as UI.

## Design Principles

1. Zero-config: the app provisions tools; the user only chooses a song and a mode.
2. Icon over prose; chips for Key / BPM / device.
3. One surface, one job.
4. Motion shows state (progress, ready, error), not decoration.
5. Contrast first on near-black surfaces.

## Accessibility & Inclusion

Body text ≥4.5:1 on `#121212`. Visible focus rings in white/near-white. Respect `prefers-reduced-motion`. Full Thai and English strings for every UI label.
