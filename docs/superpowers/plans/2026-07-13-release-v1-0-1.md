# EsanOne Convert v1.0.1 Release Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Publish EsanOne Convert v1.0.1 for users, including the current Thai-filename stem-separation and YouTube-title fixes, with verified source push, tag-triggered CI/CD, and published release downloads.

**Architecture:** Keep the source repository versioned on `main`; use the existing tag-triggered GitHub Actions workflow to build all supported desktop targets and publish artifacts to the configured `reoniazx/EsanOne-Releases` repository.

**Tech Stack:** React/Vite, Vitest, Rust/Tauri, Cargo, npm, GitHub Actions, GitHub CLI.

## Global Constraints

- The release version is exactly `1.0.1` and the Git tag is exactly `v1.0.1`.
- The version must match in `package.json`, `package-lock.json`, `src-tauri/Cargo.toml`, `src-tauri/Cargo.lock`, and `src-tauri/tauri.conf.json`.
- Preserve the existing Thai Unicode subprocess-output fix and YouTube title-resolution fix.
- Commit only the release plan, intended source fixes, version metadata, and the release instructions update; do not include generated build output or unrelated worktree changes.
- Push `main` and tag `v1.0.1` to `origin`.
- The existing `.github/workflows/release.yml` is the source of truth for CI/CD and publishes the final release to `reoniazx/EsanOne-Releases`.
